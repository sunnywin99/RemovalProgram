# RemovalProgram — 衣物去背小工具

本機執行的 Python 去背程式，用來把拍好的衣物照片自動去除背景，輸出透明底的 PNG。
提供簡單的視窗介面，可以**一次選取多張照片**批次處理。

## 安裝

需要 Python 3.9 以上版本。

```bash
pip install -r requirements.txt
```

## 使用方式

```bash
python remove_bg.py
```

1. 點「選擇照片…（可複選）」，用滑鼠或 Ctrl/Shift 複選多張衣物照片。
2. （選用）點「選擇輸出資料夾…」指定存放位置；不選的話，程式會在每張照片旁自動建立一個「去背結果」資料夾。
3. 點「開始去背」，等待處理完成即可。

輸出背景預設為**白色**（檔名 `原檔名_white.png`）；也可以改選「透明」（檔名 `原檔名_nobg.png`）。

程式會記住上次選照片的資料夾和輸出資料夾，下次開啟時會自動沿用（設定存放在使用者家目錄的 `.remove_bg_settings.json`）。

## 備註

- 第一次執行時，程式會自動下載去背用的 AI 模型（isnet-general-use，約 170MB），需要網路連線；下載完成後即可離線使用。
- 適合單一衣物主體 + 與背景有一定顏色對比的照片，效果最好。如果衣服顏色跟背景（例如米白衣服鋪在淺色床單/桌面上）很接近，邊緣可能會出現淡淡的過渡痕跡——建議盡量拍在深色或對比色的桌面/背景上。
- 底層使用 [rembg](https://github.com/danielgatis/rembg)，並開啟 alpha matting 後處理讓邊緣更乾淨。
