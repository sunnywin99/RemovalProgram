# RemovalProgram — 衣物去背小工具

本機執行的 Python 去背程式，用來把拍好的衣物照片自動去除背景，輸出透明底的 PNG。
提供簡單的視窗介面，可以**一次選取多張照片**批次處理。

## 安裝

需要 Python 3.9 以上版本。

```bash
pip install -r requirements.txt
```

## 使用方式

```bash
python remove_bg.py
```

1. 點「選擇照片…（可複選）」，用滑鼠或 Ctrl/Shift 複選多張衣物照片。
2. （選用）點「選擇輸出資料夾…」指定存放位置；不選的話，程式會在每張照片旁自動建立一個「去背結果」資料夾。
3. 點「開始去背」，等待處理完成即可。

輸出檔名格式為 `原檔名_nobg.png`，背景為透明。

## 備註

- 第一次執行時，程式會自動下載去背用的 AI 模型（u2net，約 170MB），需要網路連線；下載完成後即可離線使用。
- 適合單一衣物主體 + 單純背景（例如平拍在桌面或掛在衣架上）的照片，效果最好。
- 底層使用 [rembg](https://github.com/danielgatis/rembg)（基於 U^2-Net 的去背模型）。
